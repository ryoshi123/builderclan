# MANDATORY POST-CHANGE CHECKLIST

- Build the site and confirm it builds with no errors and no warnings.
- Open the built site and confirm every image loads and every link works.
- Confirm nothing in the reference copies was changed.
- Confirm no colour or size value was written directly into a section's styles.
- State plainly which files were changed and why.

Every instruction from the user will end with a reminder to complete this checklist. Completing this checklist is required before reporting the work as finished.

# Project rules

- The finished site must look identical to the old reference site. Never change a visual detail unless the user explicitly asks for it.
- Never edit anything in the reference copies.
- Every colour, text size and spacing value comes from one shared values file. Never write a colour or size directly into a section's styles.
- Any content that appears more than once, or is a repeating list of similar items, lives in a data file, not copied into the page markup.
- Send as little JavaScript to the visitor as possible. Prefer plain CSS for animation.
- Every image needs alternative text describing it.
- Ask the user before doing anything that could break existing behaviour.
